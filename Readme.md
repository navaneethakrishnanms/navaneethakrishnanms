🔥 Featured Projects

🌍 Wildfire Prediction System

Short-term wildfire ignition prediction up to 24 hours in advance.

A short-term wildfire risk engine that fuses NASA FIRMS active-fire data, satellite imagery, weather, terrain, vegetation, and land-cover layers across Texas and California into a single spatiotemporal feature set.

🧠 Modeling: Gradient-boosted trees (XGBoost) trained on engineered geospatial + climate features

🔍 Explainability: SHAP values help interpret why a region is flagged as higher risk

⚙️ Pipeline: Fully automated ingestion → preprocessing → feature engineering → training → evaluation, tracked end-to-end in MLflow

🌐 Geospatial tooling: Google Earth Engine + Rasterio for satellite raster processing at scale

Python XGBoost MLflow Google Earth Engine NASA FIRMS Rasterio SHAP

📝 PaperAI — AI Handwritten Answer Evaluation

97% extraction accuracy, ~1.5 minutes and ₹0.50 per paper.

An end-to-end evaluation pipeline that reads a student's handwritten answer sheet and produces a validated, defensible score — built with Vision-Language Models for handwriting understanding and reasoning-based scoring.

✍️ Extraction: VLM-based handwriting recognition tuned for messy, real classroom handwriting

👩‍🏫 Human-in-the-Loop: teachers review and override AI scores before they're final — trust by design, not an afterthought

💸 Efficiency: approximately 1.5 minutes per paper at an estimated cost of ₹0.50 per evaluation

🎤 Validated in the field: demoed live at Codissia INTEC 2026 to industry leaders, investors, startups, and academia

Python PyTorch Hugging Face Vision-Language Models OpenCV

🎥 Real-Time People Counting (Computer Vision)

Frame-accurate crowd counting for live surveillance streams.

A real-time detection-and-tracking system built on YOLOv8 with multi-object tracking, designed to hold accurate counts even in crowded, occluded scenes.

🆔 Identity persistence: unique-ID tracking across frames eliminates duplicate/double counting

⚡ Performance-tuned: inference optimized for real-time throughput across multiple camera scenarios

🧪 Tracking: supports DeepSORT or ByteTrack for persistent IDs across frames

Python YOLOv8 OpenCV DeepSORT/ByteTrack NumPy
