### 🔥 Featured Projects

#### 🌲 [Wildfire Prediction System](https://github.com/navaneethakrishnanms)
Short-term wildfire ignition prediction (~24 hours in advance) integrating NASA FIRMS, satellite imagery, weather, terrain, vegetation, and land-cover data from Texas and California. End-to-end ML pipeline with automated preprocessing, feature engineering, and SHAP-based explainability.
`Python` `XGBoost` `MLflow` `Google Earth Engine` `NASA FIRMS` `Rasterio` `SHAP`

#### 📝 [PaperAI](https://github.com/navaneethakrishnanms)
AI-powered handwritten answer evaluation product using Vision-Language Models and Computer Vision — **97% handwriting extraction accuracy**, ~1.5 minutes and ₹0.50 per paper evaluation cost, with a Human-in-the-Loop review workflow. Showcased at **Codissia INTEC 2026** to industry leaders, investors, and academia.
`Python` `PyTorch` `Hugging Face` `Vision-Language Models` `OpenCV`

#### 👥 [Real-Time People Counting Using Computer Vision](https://github.com/navaneethakrishnanms)
Real-time people counting system using YOLOv8 and multi-object tracking with unique-ID frame-by-frame tracking to reduce duplicate detections, optimized for real-time inference across surveillance scenarios.
`Python` `YOLOv8` `OpenCV` `DeepSORT/ByteTrack` `NumPy`
